# Иосиф Кушнир — сайт-резюме

Статический сайт без внешних библиотек и CDN. Шрифты и изображения включены в репозиторий.

Публикация: GitHub Pages, ветка `main`, папка `/`. Файл `.nojekyll` отключает дополнительную обработку.

## Плавность и нагрузка

- Сохранены WebGL-сцены, 3D-талисман, интерактивные демо и обе темы.
- Во время взаимодействия целевая частота основного цикла — до 60 кадров/с, в спокойной видимой сцене — до 30; фактическая частота зависит от устройства.
- На неподвижных сплошных текстовых панелях главный цикл останавливается после завершения движения и подсказок; ввод возобновляет его.
- В скрытой вкладке RAF отменяется, а при возвращении запускается снова с ограниченным шагом времени.
- Холст лица не читает размеры за пределами экрана. Бесконечные CSS-эффекты демо и индикатора статуса приостанавливаются вне экрана.
- Сохранены адаптивное снижение количества частиц и настройки уменьшения движения.

Сайт содержит только публичные демонстрационные данные. Контактные кнопки ведут на исходные контакты владельца. Для запуска локально достаточно статического HTTP-сервера; сборка и установка зависимостей не требуются.
